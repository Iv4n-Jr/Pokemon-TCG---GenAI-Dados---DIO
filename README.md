# 🃏 Banco de Dados de Cartas Pokémon
## SGBD PostgreSQL 🐘


## Sobre
Um projeto de banco de dados dedicado ao armazenamento, organização e consulta de informações sobre cartas do universo de Pokémon Trading Card Game (TCG).

O objetivo é fornecer uma estrutura clara e escalável para manipular dados como nome da carta, tipo, raridade, coleção, ataques, habilidades e muito mais.

Esse projeto foi realizado durante as atividades de "Utilizando Microsoft Copilot para escrever consultas SQL" no Bootcamp GenAI & Dados da DIO.

Se quiser extrair as tabelas e as seeds, utilize os arquivos de migration.sql das pastas dbscripts\seeds e dbscripts\tables com suas querys em um banco de dados com SGBD PostgreSQL

## Pastas
-Assets: Exemplos de cartas Pokémon
-dbscripts pasta para armazenar seeds, tabelas e views
-prompts: pasta para armazenar prompts, que no caso há um arquivo txt com o prompt utilizado no Microsoft Copilot para a geração das tabelas de Cartas e Coleções

## Ferramentas Utilizadas
-🤖 Microsoft Copilot
-📝 Visual Studio Code
